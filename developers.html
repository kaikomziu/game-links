「かるわかGAMESでログイン」を自分のサイトに付ける

あなたが作ったサイトやゲームに、かるわかGAMESのアカウントでログインできるボタンを付けられます(OAuth 2.0 の認可コードフロー + PKCE)。無料です。

使い方

まず上の「自分のアプリ」で、アプリを登録して client_id を受け取ります。そのあとの流れは次のとおりです。動くサンプルは oauth-demo.html(ソースをそのままコピーして使えます)。

1. ログイン画面へ移動する

ボタンを押したら、次のURLへ移動します(code_verifier は自分で作った43〜128文字のランダム文字列。code_challenge はそのSHA-256をbase64urlにしたもの)。

https://kaikomziu.github.io/game-links/authorize.html
  ?response_type=code
  &client_id=あなたのclient_id
  &redirect_uri=登録した戻り先URL
  &state=ランダム文字列
  &code_challenge=…
  &code_challenge_method=S256

2. 戻ってきたら code を受け取る

ユーザーが許可すると、戻り先に ?code=…&state=… がついて戻ります。state が最初に作った値と同じか必ず確かめてください(なりすまし対策)。キャンセルされたときは ?error=access_denied が付きます。code は5分・1回だけ使えます。

2→3. code を access_token に交換する

POST https://kifnzvktwbomxthzvvgy.supabase.co/functions/v1/ka-oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code&code=…&redirect_uri=…&client_id=…&code_verifier=…

返り値(JSON): {"access_token":"…","token_type":"Bearer","expires_in":3600,"scope":"profile"}
サーバーを持つアプリ(「秘密のキーを使う」で登録)は、client_secret も一緒に送ります(client_secret_post / Basic認証のどちらも可)。client_secret は、ブラウザ側のコードには絶対に入れないでください。

4. ユーザー情報を取る

GET https://kifnzvktwbomxthzvvgy.supabase.co/functions/v1/ka-oauth/userinfo
Authorization: Bearer アクセストークン
{ "sub": "…", "preferred_username": "karubiwakame", "name": "かるわか", "avatar": "🎮" }
項目意味
subアカウントの固有ID。アプリ側のユーザーIDにはこれを使ってください(表示名は変えられます)
preferred_usernameユーザー名(半角英数字)
name表示名
avatarアイコン(絵文字)

決まり・注意

  • 取れる情報は上の4つだけです(パスワード・メール・ゲームのセーブ・管理者権限は取れません)。
  • アクセストークンは1時間で切れます。リフレッシュトークンはありません。切れたら、もう一度ログイン画面へ(許可済みなら、画面を出さずにすぐ戻ります)。
  • 戻り先(redirect_uri)は、登録した文字列と完全に同じでなければ動きません。https://… か、手元確認用の http://localhost… だけ使えます。
  • 静的サイト(サーバーなし)は PKCE(S256)が必須です。
  • 戻り先を変えると、そのアプリへの許可は全員やり直しになります。
  • 同意画面には、アプリ名・作成者・戻り先のドメインが表示されます。名前に「かるわか」「公式」を含むアプリは作れません。不正なアプリは運営が停止します。
  • 設定の案内: metadata (JSON)
