かるわかGAMES API

かるわかGAMESの作品データ(ゲーム・ソフト・MOD)・評価・プレイ数・注目作品・イベント・記事を、プログラムから読めるAPIです(読み取り専用・無料)。使うには、かるわかGAMESアカウントで作る「APIキー」が必要です。

使い方

ベースURL: https://kifnzvktwbomxthzvvgy.supabase.co/functions/v1/kg-api

どのリクエストにも、APIキーを X-API-Key ヘッダーで付けます(Authorization: Bearer キー でも可)。

curl -H "X-API-Key: kgk_あなたのキー" \
  "https://kifnzvktwbomxthzvvgy.supabase.co/functions/v1/kg-api/v1/games?kind=game&genre=パズル&sort=score&limit=5"
// JavaScript (Node.js / Deno など、サーバー側で使う)
const res = await fetch("https://kifnzvktwbomxthzvvgy.supabase.co/functions/v1/kg-api/v1/games?q=ドット&limit=10", {
  headers: { "X-API-Key": process.env.KG_API_KEY },
});
const { data, meta } = await res.json();

キーは、ブラウザで動くコード(公開ページのJavaScript)には書かないでください。誰でも読めてしまい、使われすぎると止まります。自分のサーバーや、ボットなどで使ってください。

エンドポイント(すべて GET)

パス内容
/v1/games作品の一覧。絞り込み: kind(game / software / mod)、genre(ジャンル名)、q(文字で検索)、new=1(新着だけ)。並び順 sort: name(既定)/ new / plays / likes / score。limit(1〜100、既定50)・offset
/v1/games/{id}作品1つ
/v1/genresジャンルと作品数
/v1/featured注目の作品(表示順どおり)
/v1/stats全体の数字(作品数・訪問数・プレイ数・評価数)
/v1/events公開中のイベント
/v1/articles, /v1/articles/{id}公開中の記事(一覧は本文なし、1本は本文つき)
/v1/pingキーの確認と、残りの回数

作品のデータ

{
  "id": "dreamd", "title": "DReAmD", "emoji": "🍄",
  "kind": "game",              // game / software / mod
  "platform": null,            // ソフト・MODのときは Web / Windows など
  "genres": ["ホラー・ノベル"],
  "description": "…", "url": "https://…", "author": "Claude AI",
  "added": "2026-11-10", "is_new": true, "beta": true, "maintenance": false,
  "stats": { "likes": 3, "dislikes": 0, "score": 3, "plays": 120 }
}

一覧の返り値は { "data": [...], "meta": { "total", "limit", "offset", "data_updated_at" } } です。作品データは、新しい作品を足してから最大で6時間ほどで反映されます。評価・プレイ数は約1分ごとに更新されます。

決まり

  • 回数の上限は、1キーあたり 1分60回・1日5000回です。超えると 429 が返り、Retry-After ヘッダーに待つ秒数が入ります。残りの回数は、返事の X-RateLimit-Remaining-Minute / -Day でも分かります。
  • キーは1人3つまで。使わなくなったキーは、上の「取り消す」で止められます。
  • エラーは { "error": { "code", "message" } } の形です。401 はキーがない・正しくない・取り消された、404 は見つからない、400 は絞り込みの指定が正しくない、です。
  • 取れるのは公開されているデータだけです(アカウントや個人の情報は取れません)。アカウントでのログインは「かるわかGAMESでログイン」を使ってください。
  • 使い方に問題があると、運営がキーを止めることがあります。
